# SEDI Utah — Interoperability Working Group

This repository is maintained by the Utah SEDI (State Endorsed Digital Identity) program as a resource for the SEDI Interoperability Working Group.

## Purpose

The working group meets weekly to advance interoperability standards and implementation guidance for digital identity in Utah. This repository serves as the public record of that work, including meeting agendas, summaries, and shared artifacts.

## Contents

- **[`meetings/`](meetings/)** — Weekly meeting agendas and summaries, organized by date
- **[`artifacts/`](artifacts/)** — Working documents, diagrams, and reference materials produced by the group

## Participation

The SEDI Interoperability Working Group is open. Meeting details are shared through the SEDI program.

## About SEDI

SEDI is Utah’s constitutional, rights-first framework for digital identity. It establishes a secure, privacy-preserving trust layer that enables identity verification in the digital world while protecting individual liberty and limiting centralized control.
